## 📝 EXEMPLOS DE EDIÇÃO

### Mudar o Título da Hero:
1. Acesse Studio → Homepage
2. Encontre "Hero Section"
3. Edite o campo "Título Principal"
4. Clique em "Publish"

### Adicionar uma Nova Formação:
1. Acesse Studio → Homepage
2. Role até "Formações Section"
3. Clique em "Add item"
4. Preencha: Título, Descrição, Link, Texto do Botão
5. Clique em "Publish"

### Adicionar um Vídeo:
1. Acesse Studio → Homepage
2. Role até "Vídeos Section"
3. Clique em "Add item" em "Lista de Vídeos"
4. Cole o ID do YouTube (ex: `sVcR5iq1BG0`)
5. Preencha título, pessoa, descrição
6. Clique em "Publish"

### Ocultar a Seção de Depoimentos:
1. Acesse Studio → Homepage
2. Role até "Controles de Seções"
3. Desative "Mostrar Seção de Depoimentos"
4. Clique em "Publish"
