1 Introdução

Bem-vindo ao manual completo do Sanity CMS do Instituto Coaching Financeiro. Este guia foi desenvolvido para capacitá-lo a gerenciar todo o conteúdo do site de forma autônoma e profissional.

O que é o Sanity CMS?

O Sanity CMS é o sistema de gerenciamento de conteúdo que permite você editar todo o conteúdo do seu site sem precisar mexer em código. É como ter um painel de controle completo do Instituto Coaching Financeiro na palma da sua mão.

O que você pode fazer?

Editar Textos
Altere títulos, descrições e conteúdos de todas as páginas
Gerenciar Imagens
Adicione, remova ou substitua imagens e vídeos
Formações e Eventos
Crie e edite formações, eventos e suas informações
Livros
Gerencie os livros e seus links de compra
✍️
Blog
Publique e edite posts no blog
Webhooks
Configure integrações (Kommo, LeadLovers, etc)

Conceitos Importantes

Termo Significado
Documento Cada página, post ou formação é um "documento" no Sanity
Campo Cada informação editável (título, descrição, link, etc)
Publicar Suas alterações só aparecem no site após clicar em "Publish"
Rascunho Você pode salvar alterações sem publicar

2 Acessando o Sanity Studio

Aprenda como fazer login e acessar o painel de controle do Sanity CMS.

Como Acessar

Para acessar o Sanity Studio, você pode usar uma das URLs abaixo:

https://seusite.com.br/studio
ou
http://localhost:3000/studio (para desenvolvimento local)
Dica

Salve a URL do Studio nos favoritos do seu navegador para acesso rápido!

Fazendo Login

  1. Acesse a URL do Sanity Studio
  2. Faça login com suas credenciais Google ou GitHub
  3. Aguarde o carregamento completo do painel
  4. Você será direcionado ao dashboard principal
Importante

Mantenha suas credenciais de acesso em segurança. Não compartilhe com pessoas não autorizadas.

4 Editando a Homepage

Aprenda a editar cada seção da página principal do Instituto Coaching Financeiro.

Acessando a Homepage

  1. No menu lateral, clique em "Homepage"
  2. Você verá o documento "Homepage Principal"
  3. Clique no documento para abrir o editor

Hero Section (Seção Principal)

Esta é a primeira seção que os visitantes veem ao entrar no site.

Campos Disponíveis:

  • Badge: Texto pequeno acima do título (ex: "INSTITUTO COACHING FINANCEIRO")
  • Title: Título principal em destaque (ex: "TRANSFORME SUA MENTALIDADE")
  • Subtitle: Continuação do título
  • Description: Parágrafo explicativo
  • Achievements Number: Número de vidas transformadas (ex: "300.000+")
  • Primary Button Text: Texto do botão principal
  • Primary Button Link: Link do botão (ex: "#formacoes")
Como Editar
  1. Localize o campo que deseja alterar
  2. Clique no campo
  3. Digite o novo texto
  4. Clique em "Publish" no topo da página

Formações Section

Grid com cards das 8 formações principais do Instituto.

Editando um Card de Formação:

  1. Role até a seção "Formações"
  2. Clique no card que deseja editar
  3. Edite os campos:
    • Title (ex: "LCF MENTORING")
    • Description (descrição do programa)
    • Link (ex: "/formacoes/mentoria")
    • Button Text (ex: "SAIBA MAIS")
  4. Clique em "Publish"
Importante

Links internos devem começar com / (barra). Exemplo: /formacoes/mentoria

Mentor Section

Seção sobre Roberto Navarro e sua trajetória.

Adicionando um Parágrafo à Bio:

  1. Role até "Bio Paragraphs"
  2. Clique em "+ Add item"
  3. Digite o texto do novo parágrafo
  4. Arraste para reordenar se necessário
  5. Clique em "Publish"

Vídeos Section

Grid de vídeos de transformação dos alunos.

Adicionando um Novo Vídeo:

  1. Role até "Videos"
  2. Clique em "+ Add item"
  3. Preencha os campos:
    • YouTube ID (ex: "sVcR5iq1BG0")
    • Title (título do vídeo)
    • Person (nome da pessoa)
    • Description (descrição)
  4. Clique em "Publish"
Como Pegar o YouTube ID

Na URL do YouTube: https://youtube.com/watch?v=sVcR5iq1BG0

O ID é: sVcR5iq1BG0 (tudo depois do v=)

Section Controls

Controla quais seções aparecem ou ficam ocultas no site:

  • Show Mentor Section (Mostrar seção do mentor)
  • Show Videos Section (Mostrar vídeos)
  • Show Testimonials Section (Mostrar depoimentos)
  • Show Location Section (Mostrar mapa)

Marcado = Seção aparece no site
Desmarcado = Seção fica oculta

9 Configurando Webhooks

Configure as integrações com Kommo, LeadLovers e Google Sheets.

O que são Webhooks?

Webhooks são URLs que recebem os dados dos formulários do site e enviam para:

  • Kommo: CRM para gerenciar leads
  • LeadLovers: Automação de email marketing
  • Google Sheets: Planilha de backup

Acessando Configurações

  1. Menu lateral → "Integrações e Webhooks"
  2. Clique em "Configurações de Produção"
  3. Edite as URLs e credenciais conforme necessário

Kommo Webhooks

Configure webhooks específicos para cada evento/página:

  1. Role até "Kommo Webhooks"
  2. Clique em "+ Add item"
  3. Preencha:
    • Source: Nome da página (ex: "Energia do Dinheiro")
    • Webhook URL: URL do webhook do Kommo
    • Description: Descrição (opcional)
  4. Salve
Atenção

O campo Source nas páginas deve corresponder exatamente ao configurado aqui para o webhook funcionar corretamente.

10 Boas Práticas

Dicas e recomendações para usar o Sanity CMS de forma eficiente.

Checklist Antes de Publicar

  • Revisei todos os textos (ortografia e gramática)
  • Testei todos os links (CTAs, botões, links externos)
  • Verifiquei se as imagens carregam corretamente
  • Preenchi os campos de SEO (title, description, keywords)
  • Testei em diferentes dispositivos (mobile, tablet, desktop)
  • Revisei datas e horários (especialmente em eventos)

Dicas de Escrita

Títulos:

  • Use verbos de ação (Transforme, Descubra, Aprenda)
  • Seja específico
  • Use números quando possível (7 Passos, 30 Dias)

CTAs (Chamadas para Ação):

  • Seja específico: "GARANTIR MINHA VAGA" > "Clique aqui"
  • Crie urgência: "ÚLTIMAS VAGAS"
  • Use verbos no imperativo: TRANSFORME, DESCUBRA

Dicas de Imagens

Tipo Tamanho Recomendado
Hero Section 1920x1080px
Cards de Formação 800x600px
Capa de Livro 400x600px
Imagem de Blog 1200x630px
Performance

Comprima imagens antes de usar (máx. 500KB). Use ferramentas como TinyPNG ou Squoosh.

11 Suporte

Precisa de ajuda? Aqui estão os recursos de suporte disponíveis.

Problemas Comuns e Soluções

1. Não consigo publicar alterações

  • Verifique se você está logado
  • Certifique-se de clicar em "Publish" (não apenas "Save")
  • Aguarde alguns segundos e recarregue o site
  • Limpe o cache do navegador (Ctrl+Shift+Delete)

2. Imagem não aparece no site

  • Verifique se a URL está correta
  • Teste abrindo a URL em uma nova aba
  • Use URLs completas: https://... ou /images/...

3. Link não funciona

  • Links internos devem começar com /
  • Links externos devem começar com https://
  • Para âncoras, use #nome-da-secao
